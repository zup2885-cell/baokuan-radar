# 爆款雷达

电脑上的抖音选题和文案拆解工具。配置并登录专用小号后，后台会按节奏取公开热榜、挑搜索词、筛选视频，再把逐字稿和拆解结果留在本机。

## 怎么打开

1. 双击桌面上的「爆款雷达.command」。本次修复没有修改这个启动文件。
2. 浏览器中打开的地址应为 **http://127.0.0.1:8777**，仅供这台电脑使用。
3. 如果打不开，先确认后台界面服务已安装并运行。安装或更新需要在工具目录的终端执行 `./install.sh`；本次检查没有运行安装脚本，也没有替你重载后台任务。修改后的后台配置要重新安装后才生效。

首次安装需使用本机已有的 ChatGPT/Codex 登录状态、抖音创作台的 dy-cli 环境，以及 video-tools 的 faster-whisper 和 small 模型。工具不会自动安装这些依赖。目录和解释器被移动或升级后，可能需要更新配置路径。

## 第一次使用：扫码登录小号

1. 打开「设置」，填写「账号领域」，例如「汽车、车评讲解」。固定关键词用逗号分隔，保存设置。
2. 点「扫码登录小号」，等待独立浏览器窗口出现。
3. 用**专门的小号**所在的抖音 App 扫码，并在手机上确认登录。不要使用主号。
4. 等界面提示登录成功。以后使用同一份独立浏览器资料，通常不用每天扫码；登录失效时会再次提醒。

这个工具的小号资料放在自己的数据目录内，不使用你日常浏览器或抖音创作台的账号 Cookie。登录、验证、后台搜索和拆解共用任务锁，上一轮未结束时请稍后再试。

## 遇到验证、登录失效或限流

| 提示 | 怎么处理 |
| --- | --- |
| 需要扫码登录 | 到「设置」重新扫码。仅仅存在 Cookie 文件，不代表登录仍有效。 |
| 抖音要求验证 | 点「打开验证窗口」，由本人完成验证。观察到正常搜索响应后窗口会自动关闭，并恢复排队。直接关窗口、没完成验证或无法确认结果时，继续暂停。 |
| 暂时限流 | 从检测到限流起暂停搜索 24 小时，到期后按原间隔尝试。立即运行、重新登录和打开验证窗口都不能跳过暂停期。 |
| 搜索超时、页面读取失败 | 关键词保留在队列中，后续按间隔重试；若持续出现，请检查网络或交给维护者检查页面是否改版。 |
| 拆解失败 | 打开视频详情查看提示，稍后点「重新拆解」。已取得的逐字稿会保留，重试时优先复用。 |

需要登录、遇到验证/限流，以及当天队列处理结束时，会尝试发送 macOS 通知。通知能否显示还取决于系统权限和专注模式，也可以在「设置」看状态和运行记录。需要登录或本人验证的暂停不会因为过了一天就自行解除。

## 每天怎么运行

- 默认每天 **8:00–22:00（北京时间）**运行，后台每 30 分钟检查一次。电脑关机、休眠或退出当前 macOS 用户会影响运行，唤醒后才可能继续。
- 每天取一次热榜，让本机 Codex 批量分类，再按账号领域生成关键词。热榜获取、分类和挑词分别记状态；分类失败不阻断挑词或热榜展示，后续轮次重试。
- 默认每天最多 6 个关键词，固定关键词计入总数且优先排列，重复词只算一次。每天的关键词选好后，当天不因修改领域或固定词重新生成，新的选题设置从下一天生效。
- 默认每两次搜索至少间隔 60 分钟，一轮最多搜一个词。「立即运行一次」可在自动运行关闭或运行时段之外手动处理一轮，仍遵守间隔和暂停规则。
- 每词最多读取 30 条搜索结果；默认挑点赞不少于 1 万、最近 7 天发布的前 3 条。一轮最多拆解 3 条，未拆完的已选视频留到后续轮次。当日没来得及搜索的词不会在第二天继续排队。
- 爆款倍数 = 点赞数 ÷ 粉丝数。先按倍数、再按点赞数排序；粉丝未知或为 0 时显示「倍数未知」，排在已知倍数之后。发布时间缺失、无效或在未来的结果不会通过最近天数门槛。
- 同一视频只入库一份，已拆过的不会再次自动拆解，也不会覆盖收藏和备注。失败的视频可手动重试。
- 视频下载后用本地模型转文字，正常结束或捕获到失败时删除视频，只留文字。下载或转写失败时，可基于标题进行拆解，并要求说明材料缺口；没有逐字稿的分析参考价值更低。进程被强制结束时，临时视频可能来不及删除。

「今日爆款」可切换历史日期；详情中能打开原视频、收藏、编辑标签和备注、复制模板。「收藏库」支持搜索标题、逐字稿、拆解、标签和备注，也可按标签筛选。修改标签或备注后记得点保存，自动刷新会保留正在编辑的内容。

## 热榜按赛道筛选

「热榜」顶部提供「全部」「和我相关」和各赛道按钮，当前按钮高亮，按钮后的数字是当天该类别的总条数，切换筛选不会改变这些总数。未分类也有独立按钮；未判断相关性不等于“不相关”，暂不计入「和我相关」。

赛道列表在 [`config/hot_tracks.json`](config/hot_tracks.json)，可以增删或调整顺序。每个热词只能归一个赛道，相关性另外判断；跨赛道但有自然结合点的话题，也可以与账号领域相关。配置必须是非空、不重复的文字列表，每项最多 20 字；「全部」「和我相关」「未分类」是保留名称。建议保留「其他」作为兜底类别。

分类通过一次 `radar.codex` 调用，把当天待分类词条一起发送，按 [`schemas/hot_classification.json`](schemas/hot_classification.json) 返回结果。程序检查原始排名、原词、数量、重复、赛道范围和布尔类型，全部合法后才一次入库。再次运行只处理未分类或已失效的词条，已有有效分类不会重复调用；挑词单独调用，便于分别重试。

旧数据库首次连接会自动为 `hot` 表添加 `track`、`related`、`classification_key` 三列，保留热词和其他数据。今天已抓过的热榜也会在下一次有效 tick（自动时须在运行时段内）补分类。也可在热榜页点「补分类」：只分类已存在的今日热词，不抓榜、不搜索，也不打开登录或验证窗口；任务仍使用原来的共用锁。

分类失败时热词保留，显示「未分类」，运行记录说明失败，下一轮自动重试。修改「账号领域」或赛道配置后，旧分类立即按未分类显示，下一轮或点「补分类」重新判断；已经选好的当天关键词继续沿用，下一天才重新选词。

接口：`GET /api/hot?day=YYYY-MM-DD` 返回 `items`、`tracks`、`counts`、`field`、`day`；可加 `track=汽车`（中文需 URL 编码）或 `related=1`，两者并用时取交集。`related=0` 关闭相关筛选。`counts.all`、`counts.related`、`counts.tracks` 始终按整天计算，缺失热度保留为空、真实的 0 保留为 0。`POST /api/classify-hot` 使用任务队列补分类。

## AI 爆款分析

视频详情的「AI 爆款分析」保留总结、开头钩子、结构、模板、角度、受众、原因、标签和材料缺口，并增加：

- **开头前 3 秒分析**：引用开头文字，说明具体手法和可能留人的理由。现有转写没有逐句时间戳，只能按开头文字推测，无法确认真实前 3 秒；只有标题时不能判断实际开头。
- **爆款原因**：2–4 条，每条带连续原文证据并标为「推测」。用反事实问题寻找主要机制，考虑情绪、分享动机、留人和内容兑现，也考虑粉丝基础、时机、投流未知、随机性和单样本偏差。
- **值得借鉴**：逐条给原文证据，以及如何用到当前账号领域的具体场景和改法。
- **不建议照搬**：说明不能直接复用的内容、原因及替代做法。
- **可以直接改的选题**：2–3 个，包含原创开场、内容提纲和借鉴的机制，缺少个人实证时应补自己的素材。

新版结果使用 `analysis_version: 2`，记录分析时的 `account_field`。程序校验结构、必填字段、条数和推测标记；钩子、开头证据、原因和借鉴点的引用还须出现在实际输入的逐字稿或标题中。校验不能保证解释正确，仍需要人工判断。

旧结果直接读取，无需补字段或批量重算；界面提示「旧版分析」。点「重新拆解」使用当前领域生成新版，优先复用逐字稿，保留收藏、标签和备注。重新拆解失败时，界面保留上次结果并显示失败提示。修改领域不会自动重算旧分析，详情会提醒重新拆解。

目前没有把视频画面、音频、完播率、留存曲线或评论正文送入分析，不能据此声称看到了镜头、听到了语气，或证实了推荐原因。

## 设置范围

每天关键词数 1–12，每词拆解数 1–10，最近天数 1–180，搜索间隔 20–1440 分钟。固定关键词最多 10 个、每个最多 20 字，数量不能超过每天关键词总数。运行时段必须是同一天内先开始再结束；例如 8 到 22，或 0 到 24。

标签会去重，每个最多保留 12 字、最多 12 个；备注最多 5000 字。参数错误会提示原因，整次设置不会部分保存。

## 数据存在哪

默认数据目录：`~/Library/Application Support/BaokuanRadar`。

在访达选择「前往」→「前往文件夹」，粘贴这个路径即可打开。

| 文件或文件夹 | 内容 |
| --- | --- |
| `radar.sqlite3` | 设置、热榜、关键词、视频信息、逐字稿、拆解、收藏、标签、备注和运行记录 |
| `dy-account/cookies/default.json` | 专用小号的登录资料，请勿分享 |
| `dy-account/browser-profile` | 小号独立浏览器资料，请勿分享 |
| `media` | 临时视频，转写后删除；强制终止产生的残留可在确认任务未运行时清理 |
| `logs/server.log`、`logs/tick.log` | 安装后台任务后产生的服务和定时任务日志 |
| `codex-out`、`*.lock` | 临时结构化输出和任务锁文件，锁文件存在不代表任务还在运行 |

备份前先停止后台任务，再复制整个数据目录。不要把账号资料、逐字稿或日志放进公开仓库。开发和测试可在启动进程前设置 `BAOKUAN_DATA` 来换数据目录，界面服务与定时进程必须使用相同目录；默认安装脚本仍使用上述正式目录。

## 怎么卸载后台任务

在「爆款雷达」目录打开终端，执行：

```sh
./install.sh remove
```

这会停止并移除界面服务和每 30 分钟的任务，不删除收藏、账号资料和工具代码。需要恢复时重新执行 `./install.sh`。关闭网页只会关闭界面，不会停止后台搜索；临时停用可在「设置」关闭「每天自动运行」并保存。

## 风险和判断边界

**这是非官方读取方式，违反抖音用户协议，小号可能被限制或封禁，务必用专用小号。** 放慢频率也不能保证账号安全。遇到验证码和风控就停下来，由本人处理；工具不破解验证码，也不绕过验证。

公开热榜、网页结构和视频下载地址可能变化或失效，粉丝、点赞等数据可能缺失；筛选只代表页面返回的有限样本，不能保证找到全平台爆款。倍数高不等于内容一定好，也不能排除投流等因素。语音识别可能有错字，Codex 对爆款原因的解释是推测，需要自己复核。

视频转写在本机进行；热榜分类、挑词和文案拆解会通过已登录的 Codex 服务处理，热榜、账号领域、视频描述、指标和逐字稿会作为输入发送给该服务。分类与挑词是独立调用，失败重试及修改领域后的重分类也会占用 ChatGPT/Codex 额度，不能理解为全程离线。
